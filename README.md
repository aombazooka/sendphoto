# Photo Delivery — ระบบส่งงานรูปภาพให้ลูกค้า

ช่างภาพวางลิงก์ Google Drive / Google Photos / Immich → ได้ลิงก์แกลเลอรีสวย ๆ ส่งให้ลูกค้า
ลูกค้าเปิดได้ทันที (ไม่ต้องเข้าสู่ระบบ) คัดรูป บันทึกลง Photos บนมือถือ ดาวน์โหลด ZIP ซื้อภาพ หรือหาภาพของตัวเองด้วยใบหน้า

## เริ่มใช้งาน (XAMPP)
1. เปิด Apache + MySQL ใน XAMPP
2. คัดลอก `config.example.php` เป็น `config.php` แล้วแก้รหัสผ่าน MySQL (ถ้าไม่มี `config.php` ระบบจะใช้ค่าตัวอย่าง)
3. เข้า `http://localhost/sendphoto/admin/` → สร้างบัญชีแอดมินกลาง (ชื่อระบบ อีเมล รหัสผ่าน)
4. ฐานข้อมูล `sendphoto` และตารางถูกสร้าง/อัปเดตอัตโนมัติเมื่อเปิดเว็บ
5. แนะนำเปิด `extension=gd` ใน `php.ini` (ย่อภาพที่ Google ไม่มีภาพย่อ และทำลายน้ำ)

## ระบบสมาชิก (หลายร้าน)
- **สมัครสมาชิก** `admin/signup.php` → ตั้งชื่อร้านเอง ได้ทดลองใช้ฟรี (ค่าเริ่มต้น 7 วัน)
- **แพ็กเกจ** (เมนู “แพ็กเกจ” ของร้าน) → เลือกรายเดือน/รายปี → สแกน QR พร้อมเพย์ (ใส่ยอดให้อัตโนมัติ) → แนบสลิป
- **ฟีเจอร์ตามแพ็กเกจ:** แอดมินกลางติ๊กได้ว่าแต่ละแพ็กเกจ (และช่วงทดลองใช้) มี ♡ คัดรูป · ฿ ลายน้ำ+ขายรูป · ☺ ค้นหาด้วยใบหน้า หรือไม่ (หน้า “ระบบ”)
- **แอดมินกลาง** (role `admin`) มีเมนูเพิ่ม: สมาชิก · ชำระเงิน (อนุมัติ/ไม่อนุมัติสลิป) · ระบบ (ราคาแพ็กเกจ, วันทดลองใช้, บัญชีรับเงิน)
- อนุมัติสลิปแล้วต่ออายุอัตโนมัติ โดยนับต่อจากวันหมดอายุเดิมถ้ายังไม่หมด
- สมาชิกหมดอายุ → สร้าง/แก้ไขแกลเลอรีไม่ได้ แต่ลิงก์ลูกค้ายังเปิดได้อีก N วัน (ตั้งที่หน้า “ระบบ”, ค่าเริ่มต้น 7) แล้วจึงปิด
- ระงับบัญชี → เข้าสู่ระบบไม่ได้ และลิงก์ลูกค้าของร้านนั้นปิดทันที
- แต่ละร้านเห็นเฉพาะแกลเลอรี โลโก้ ช่องทางติดต่อ และคำสั่งซื้อของตัวเอง · สลิปเก็บใน `data/slips` (เปิดจากเว็บตรง ๆ ไม่ได้)

## การสร้างแกลเลอรี
1. ใน Google Drive: คลิกขวาโฟลเดอร์ → แชร์ → การเข้าถึงทั่วไป = **ทุกคนที่มีลิงก์**
2. หน้าจัดการ → สร้างลิงก์แกลเลอรี → วางลิงก์ → กด **ตรวจลิงก์**
3. ใส่ชื่ออัลบั้ม ภาพปก โลโก้ อายุลิงก์ → **สร้างลิงก์แกลเลอรี** → คัดลอกลิงก์ส่งลูกค้า
4. เปิดหน้าแกลเลอรีค้างไว้สักครู่ ระบบจะเตรียมภาพย่อล่วงหน้าให้ลูกค้าเปิดได้เร็ว

ลิงก์ที่รองรับ (1 บรรทัดต่อ 1 ลิงก์ ผสมกันได้)
- โฟลเดอร์ Google Drive (รวมโฟลเดอร์ย่อย 3 ชั้น — แต่ละโฟลเดอร์ย่อยเป็น 1 หมวด) / ไฟล์ Google Drive
- อัลบั้มที่แชร์จาก Google Photos (`photos.app.goo.gl/...`)
- ลิงก์แชร์ Immich (`https://immich.example.com/share/<key>` หรือ `/s/<slug>`) — ลิงก์ที่ตั้งรหัสผ่านไว้ยังไม่รองรับ
- ลิงก์รูปภาพโดยตรง

> **แนะนำ:** ใส่ Google Drive API Key ที่หน้า “ตั้งค่าร้าน” — ดึงโฟลเดอร์ใหญ่ได้ครบและเสถียรกว่า และแสดงขนาดไฟล์ (MB) บนหน้าปกได้

## ขายรูป
1. ตั้งค่าร้าน › ขายรูป: ใส่ **พร้อมเพย์ของร้าน** ชื่อบัญชี และข้อความลายน้ำ (เว้นว่าง = ชื่อร้าน)
2. หน้าแก้ไขแกลเลอรี › **฿ ลายน้ำ + ขายรูป**: เปิด “ขายภาพ” ตั้งราคาต่อภาพ และ/หรือราคาซื้อทั้งหมด
3. ลูกค้าเลือกภาพ → ซื้อ → สแกน QR → แนบสลิป → คุณได้แจ้งเตือน → กด **อนุมัติ** ในส่วน “คำสั่งซื้อ”
4. ลูกค้าโหลดได้เฉพาะภาพที่จ่ายแล้ว (ตรวจที่ server ทุกครั้ง) · ถ้าลูกค้าเปลี่ยนเครื่อง กด **ลิงก์ดาวน์โหลดของลูกค้า** แล้วส่งให้ทาง LINE
5. คำสั่งซื้อที่ไม่แนบสลิปเกิน 30 วันจะถูกลบโดย cron

## ค้นหาด้วยใบหน้า (PDPA)
- ปิดอยู่เป็นค่าเริ่มต้นทุกแกลเลอรี — เปิดเฉพาะงานที่จำเป็น และแจ้งผู้ร่วมงานว่ามีบริการนี้
- ระบบเก็บเฉพาะ **ค่าตัวเลขของใบหน้า** (128 ค่า) ไม่ใช่ภาพ และไม่ส่งข้อมูลนี้ให้ลูกค้า
- เซลฟี่ของลูกค้า **ประมวลผลในเครื่องลูกค้าเท่านั้น** ส่งไปค้นหาเพียงค่าตัวเลข ซึ่งไม่ถูกบันทึก · ลูกค้าต้องติ๊กยินยอมก่อน
- ลบดัชนีได้ทุกเมื่อ (และถูกลบอัตโนมัติเมื่อลบแกลเลอรีหรือภาพ)
- ใช้ไลบรารี face-api (@vladmandic/face-api 1.7.13) และโมเดลจาก jsDelivr — โหลดเฉพาะเมื่อมีคนใช้ (~8 MB ครั้งแรก)

## การแจ้งเตือน
ตั้งค่าที่ ตั้งค่าร้าน › การแจ้งเตือน: เลือกเหตุการณ์ (คัดรูป · ลูกค้าเปิดลิงก์ · ดาวน์โหลด · สลิปซื้อภาพ · ลิงก์ใกล้หมดอายุ)
- **ในเว็บ:** ตัวเลขที่เมนูอัปเดตเองทุก 30 วินาที + กล่องเด้ง + เสียง + ป๊อปอัปเบราว์เซอร์ (ต้องเปิดหน้าจัดการไว้)
- **Web Push:** เด้งแม้ปิดหน้าเว็บ — ต้องใช้ HTTPS (หรือ localhost) · iPhone ต้อง “เพิ่มไปยังหน้าจอโฮม” ก่อน
- **LINE Official Account** (Messaging API push ถึงตัวคุณเอง) และ **Telegram** — มีขั้นตอนในหน้าตั้งค่า

## งานตั้งเวลา (cron)
`cron.php` ควรรันทุกชั่วโมง (เปิดจากเว็บไม่ได้) — แจ้งลิงก์ใกล้หมดอายุเข้า LINE/Telegram/Web Push, ลบคำสั่งซื้อค้าง, ล้างแคชภาพเก่า
- Windows (XAMPP): `schtasks /Create /SC HOURLY /TN "sendphoto-cron" /TR "C:\xampp\php\php.exe C:\xampp\htdocs\sendphoto\cron.php"`
- Linux: `0 * * * * php /var/www/sendphoto/cron.php >/dev/null 2>&1`
- ตั้ง `base_url` ใน `config.php` ให้เป็นที่อยู่เว็บจริง เพื่อให้ลิงก์ในแจ้งเตือนถูกต้อง
- หน้า “ระบบ” ของแอดมินกลางแสดงเวลาที่ cron ทำงานล่าสุด

## ความปลอดภัย / PDPA
- ลิงก์ลูกค้าเป็นโทเคนสุ่ม 16 ตัวจาก `random_bytes()` เดาไม่ได้ · สร้างลิงก์ใหม่ได้ (ลิงก์เดิมใช้ไม่ได้ทันที)
- ตรวจวันหมดอายุ/สถานะปิดลิงก์ที่ server ทุกครั้ง ทั้งหน้าเว็บ ภาพ การดาวน์โหลด การคัดรูป การซื้อ และการค้นหาใบหน้า
- ภาพทุกภาพผ่าน `media.php` / `download.php` — browser ไม่เห็น Drive file ID หรือ Immich key · แกลเลอรีที่ขายรูปส่งเฉพาะภาพที่มีลายน้ำ
- `noindex` ทุกหน้า + `robots.txt` · Prepared statements ทุก query · escape ทุกข้อความ · CSRF ในหน้าจัดการ
- `.git`, `config.php`, `cron.php` เปิดจากเว็บไม่ได้ · `config.php`, `data/`, `uploads/` ไม่อยู่ใน git


## ขึ้นเซิร์ฟเวอร์จริง
- ต้องใช้ **HTTPS** (บันทึกลง Photos บน iPhone และ Web Push ใช้ได้เฉพาะ HTTPS)
- ตั้งรหัสผ่าน MySQL และ `base_url` ใน `config.php` · เปิด `mod_rewrite` และ `AllowOverride All`
- PHP 8.1+ พร้อม curl, pdo_mysql, fileinfo, openssl, gd
- ตั้ง cron ทุกชั่วโมง (ดูหัวข้อด้านบน)
