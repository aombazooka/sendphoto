# Photo Delivery — ระบบส่งงานรูปภาพให้ลูกค้า

ช่างภาพวางลิงก์ Google Drive / Google Photos / Immich → ได้ลิงก์แกลเลอรีสวย ๆ ส่งให้ลูกค้า
ลูกค้าเปิดได้ทันที (ไม่ต้องเข้าสู่ระบบ) กด ♡ เลือกภาพ แล้วบันทึกลง Photos บนมือถือ หรือดาวน์โหลดเป็น ZIP

## เริ่มใช้งาน (XAMPP)
1. เปิด Apache + MySQL ใน XAMPP
2. เข้า `http://localhost/sendphoto/admin/` → สร้างบัญชีแอดมินกลาง (ชื่อระบบ อีเมล รหัสผ่าน)
3. ฐานข้อมูล `sendphoto` และตารางถูกสร้างอัตโนมัติ (ตั้งค่าการเชื่อมต่อได้ที่ `config.php`)

## ระบบสมาชิก (หลายร้าน)
- **สมัครสมาชิก** `admin/signup.php` → ตั้งชื่อร้านเอง ได้ทดลองใช้ฟรี (ค่าเริ่มต้น 7 วัน)
- **แพ็กเกจ** (เมนู “แพ็กเกจ” ของร้าน) → เลือกรายเดือน/รายปี → สแกน QR พร้อมเพย์ (ใส่ยอดให้อัตโนมัติ) → แนบสลิป
- **แอดมินกลาง** (role `admin`) มีเมนูเพิ่ม: สมาชิก · ชำระเงิน (อนุมัติ/ไม่อนุมัติสลิป) · ระบบ (ราคาแพ็กเกจ, วันทดลองใช้, บัญชีรับเงิน)
- อนุมัติสลิปแล้วต่ออายุอัตโนมัติ โดยนับต่อจากวันหมดอายุเดิมถ้ายังไม่หมด
- สมาชิกหมดอายุ → สร้าง/แก้ไขแกลเลอรีไม่ได้ แต่ลิงก์ลูกค้ายังเปิดได้อีก N วัน (ตั้งที่หน้า “ระบบ”, ค่าเริ่มต้น 7) แล้วจึงปิด
- ระงับบัญชี → เข้าสู่ระบบไม่ได้ และลิงก์ลูกค้าของร้านนั้นปิดทันที
- แต่ละร้านเห็นเฉพาะแกลเลอรี โลโก้ และช่องทางติดต่อของตัวเอง · สลิปเก็บใน `data/slips` (เปิดจากเว็บตรง ๆ ไม่ได้)

> **อัปเกรดจากเวอร์ชันร้านเดียว:** บัญชีเดิมกลายเป็นแอดมินกลางโดยอัตโนมัติ เข้าสู่ระบบด้วยอีเมล `admin` + รหัสผ่านเดิม
> แล้วเปลี่ยนเป็นอีเมลจริงที่หน้า “ตั้งค่าร้าน” · แกลเลอรีเดิมทั้งหมดเป็นของบัญชีนี้

## การสร้างแกลเลอรี
1. ใน Google Drive: คลิกขวาโฟลเดอร์ → แชร์ → การเข้าถึงทั่วไป = **ทุกคนที่มีลิงก์**
2. หน้าจัดการ → สร้างลิงก์แกลเลอรี → วางลิงก์ → กด **ตรวจลิงก์**
3. ใส่ชื่ออัลบั้ม ภาพปก โลโก้ อายุลิงก์ → **สร้างลิงก์แกลเลอรี** → คัดลอกลิงก์ส่งลูกค้า

ลิงก์ที่รองรับ (1 บรรทัดต่อ 1 ลิงก์ ผสมกันได้)
- โฟลเดอร์ Google Drive (รวมโฟลเดอร์ย่อย 3 ชั้น) / ไฟล์ Google Drive
- อัลบั้มที่แชร์จาก Google Photos (`photos.app.goo.gl/...`)
- ลิงก์แชร์ Immich (`https://immich.example.com/share/<key>` หรือ `/s/<slug>`) — ลิงก์ที่ตั้งรหัสผ่านไว้ยังไม่รองรับ
- ลิงก์รูปภาพโดยตรง

> **แนะนำ:** ใส่ Google Drive API Key ที่หน้า “ตั้งค่า” — ดึงโฟลเดอร์ใหญ่ได้ครบและเสถียรกว่า และแสดงขนาดไฟล์ (MB) บนหน้าปกได้
> (ถ้าไม่ใส่ ระบบจะอ่านโฟลเดอร์แบบสาธารณะซึ่งไม่มีข้อมูลขนาดไฟล์)

## ความปลอดภัย / PDPA
- ลิงก์ลูกค้าเป็นโทเคนสุ่ม 16 ตัวจาก `random_bytes()` เดาไม่ได้ · สร้างลิงก์ใหม่ได้ (ลิงก์เดิมใช้ไม่ได้ทันที)
- ตรวจวันหมดอายุ/สถานะปิดลิงก์ที่ server ทุกครั้ง ทั้งหน้าเว็บ ภาพ และการดาวน์โหลด
- ภาพทุกภาพผ่าน `media.php` / `download.php` — browser ไม่เห็น Drive file ID หรือ Immich key
- `noindex` ทุกหน้า + `robots.txt` · Prepared statements ทุก query · escape ทุกข้อความ · CSRF ในหน้าจัดการ

## โครงสร้าง
```
admin/        หน้าจัดการ (login, signup, อัลบั้ม, ตั้งค่าร้าน, billing)
              + แอดมินกลาง: members, member, payments, platform, slip
share.php     หน้าแกลเลอรีของลูกค้า (/s/{token})
media.php     proxy ภาพย่อ/ภาพตัวอย่าง (แคชไว้ที่ data/cache)
download.php  ดาวน์โหลดต้นฉบับทีละภาพ / ZIP / ใช้กับปุ่ม "บันทึกภาพ"
inc/          bootstrap (DB, helper), account.php (สมาชิก/แพ็กเกจ/ชำระเงิน/PromptPay), google.php (Drive/Photos/Immich), zipstream, proxy
uploads/      ภาพปกและโลโก้ที่อัปโหลด
config.php    การเชื่อมต่อ MySQL และขนาดชุดภาพที่ส่งเข้าเมนูแชร์
```

## ขึ้นเซิร์ฟเวอร์จริง
- ต้องใช้ **HTTPS** (ปุ่ม “บันทึกภาพลง Photos” ผ่านเมนูแชร์ใช้ได้เฉพาะ HTTPS)
- เปลี่ยนรหัสผ่าน MySQL ใน `config.php` · ต้องเปิด `mod_rewrite` และ `AllowOverride All`
- PHP 8.1+ พร้อม curl, pdo_mysql, fileinfo
